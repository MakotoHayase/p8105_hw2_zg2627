``` r
# Keep the variables needed for the analysis and recode entry as logical
subway_clean =
  subway_data |>
  select(
    line,
    station_name,
    station_latitude,
    station_longitude,
    route1:route11,
    entrance_type,
    entry,
    vending,
    ada
  ) |>
  mutate(
    entry = entry == "YES"
  )

dim(subway_clean)
```

exits, including subway line and station name, station coordinates,
routes served, entrance type, whether entry is allowed, vending
availability, and ADA accessibility. After cleaning, the dataset
contains 1868 observations and 19 variables.

``` r
# Reshape route variables into a tidy format
subway_tidy =
  subway_clean |>
  mutate(
    across(route1:route11, as.character)
  ) |>
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    values_to = "route_name"
  ) |>
  filter(!is.na(route_name))
```

The cleaned dataset is not fully tidy because route information is
stored across multiple columns (route1 through route11). After reshaping
these columns into route_number and route_name, each variable is stored
in its own column and each route-station combination occupies one row.

``` r
# Keep stations served by the A train
```
