``` r
# Keep the variables needed for the analysis and recode entry as logical
subway_clean =
  subway_data |>
  select(
    line,
    station_name,
    station_latitude,
    station_longitude,
    route1:route11,
    entrance_type,
    entry,
    vending,
    ada
  ) |>
  mutate(
    entry = entry == "YES"
  )

dim(subway_clean)
```

    ## [1] 1868   19

The cleaned subway dataset contains information on subway entrances and
exits, including subway line and station name, station coordinates,
routes served, entrance type, whether entry is allowed, vending
availability, and ADA accessibility. During cleaning, I retained the
variables relevant to the analysis and converted entry from a character
variable (“YES” / “NO”) to a logical variable. The resulting dataset
contains 1868 observations and 19 variables. The data are not fully tidy
because route information is stored across multiple columns (route1
through route11).

``` r
# Reshape route variables into a tidy format
subway_tidy =
  subway_clean |>
  mutate(
    across(route1:route11, as.character)
  ) |>
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name"
  ) |>
  filter(!is.na(route_name))
```
